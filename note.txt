Backend
----------
-backend of a webapp is the server-side part of the application that users do not directly see.it handle logic,database operations,authentication,APIs,and commucnication between the front-end and database.
- main responsibilities of backend
    -server logic
    -database management
    -authentication & security
    -APIs
    -business logic
-popular backend technologies: javascript(node js), python, php, java,c#
    -frameworks:Express.js,NextJS,DJango,Larvel,spring Boot...
    -Databases used with backend:mongodb,MySql, Postgresql,SQLite,Firebase....

database
-----------
-a database is an organized collection of data stored electronically so that it can easily accessed, managed and, updated
-2 types of database
  -relational database(SQL Based)
  -NoSql database
-3 SQL: Structured query Language -used to interact with relational Databases
    -Here data are stored as table
    -row(record): one entry in table indicate one item stored in table
    -column(field):attribute of data stored in table.

mongodb
-----------
-MongoDB is NoSql, document oriented db, that store data in JSON like format(BSON) instead of table
-Features:
   -Schema-less(Flexible structure)
   -scalable
   -designed for modern application

-key Features
    -collection:equalent to table in SQL
    -document:a single record (JSON-like object)
    -BSON:Binary version of JSON used internally
    -_id fields:every document has a unique key value

-CRUD operations:
     -Read: to get documents from collection 
     -find():used to get all documents, usage collection_name.find(),to query from collection: find(condition), condition should be in object
     -findOne(condition):used to get single document.
 -Create: to insert document into the collection
     -insertOne(document): used to insert on document into a collection,document can be an object.
     -insertMany([doc1, doc2,..]):used to insert multiple documents at a time into a collection.
 -Update:to update document
     -updateOne():to update single document
      -updateMany():to update multiple document at a time.
       syntax:updateMany({filter},{update_query:{field1:value1},{field2:value2}})
    -Delete: to delete document from collection
       -deleteOne():to delete single document
       -deleteMany():to delete single document
 -Query Operators:
    -comparison: syntax: {field:{comparison_query:value}}
      ex: #eq,$ne,$gt,$lt,$gte,$lte,$in
    -Logical: syntax:{logical_query:[{field1:value1},{field2:value2}]}
        ex:$and, $or, $not
    -Evaluation:syntax:{field:{evaluation_query:value}}
       ex:$regex, $text, $where
    -Additional operators: count(), limit(), sort()
 Update operators:
    -Field:$inc,$set,$unset, $rename,$currentData
    -Array:$pop,$push

-Indexing: used to make data searchinf faster in mongoDB.
  -why use indexing:Faster find() queries, sorting, improves search fields, Better performance for large data.
     syntax:db.collection_name.createIndex({fieldName:1})

2.its uses: 
    web servers, rest APIs, backend applications, mern stack back ends
3.use Express.js: easy routing, middleware support, rest API creation, fast development, works with MongoDB, Large Ecosystem.


-Authentication and Authorization:
   -Authentication is the process of verifying the identity of a users
   -Authorization means checking what permissions a user has after login. performed using JWT(json web token)


-middleware: function that runs between the request and response cycle
  -middleware can 
    -pass control to the next middleware/controller function
    -sends response directly
    -Handle errors
   - to create middleware:create a function with minimum 3 arguments(req,res,next)

   JWT(json web token)
   --------------------
   1.JWT is a secure way to authenticate users and share user data between client and server 
   2. what is jwt : when user login successfully:
       -server creates a token using jwt
       -send token to client
       -client store token 
       -client send token with future requests
   3.JWT structure: it has parts  -Header.payload,Signature
         -Header: Algorithm+token type
         -Payload: user data can be stored for future use
         -signature: used to varify token is validation
   4.install json webtoken using npm install jsonwebtoken
   5. create token :use sign method
   6. verify token : use verify method

   -Multer
   -----------------
   1. multer is a node js middleware for handling multipart/formdata
   2. to use multer :installation: npm i multer
   3. usage of multer
     -multer adds a body object and  file or files object to the request body 
     -the body object contains the values of the text fields of the formdata
     - the file or files object contains the file uploaded via the format
     -define storage for uploaded files
     -it can apply filter as well
CORS-Cross Origin Resource Sharing
-----------------------------------
1. it is a browser security feature that control whether a frntend from one origin can access resources from another origin 
2. Origin = Protocol +Domain +Protocol
3. If front end and backend have different origin, browser may block request.
4. To enable cors
  -install cors package : npm install cors
  -use cors in the app
5. CORS= Permission Systemfor cross-origin browser request.

STEPS TO CREATE AN EXPRESS Server
------------------------------------
1. Create a folder to hold all files of project.
2. create project configuration file(package.json) using the command: npm init -y
3. update package.json file script by start as "node index.js", where index.js is the main entry file of project.
4.install packages: express,cors, dotenv
5. create .env file to hold project secrets/configuration data
6. create .gitignore file to add files/folders to avoid when adding to git
7. create index.js file where we define  express server
  -import all packages.
  -create server using express package 
  -enable cors in server 
  -set up port for server app 
  -startserver to listen client request to that port
  -resolve api(get request to http://localhost:3000/) using express
     -syntax: server.httpRequest(url,callback),use callback to define the logic to resolve the request
8. run the server using node index.js
